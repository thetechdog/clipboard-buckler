      How to use

      Whenever a site tries to copy something to your clipboard, a 30‑second prompt dialog appears. You can choose to allow or block it once, or always/never for that (sub)domain:
      Yes/No apply once;
      Always → whitelist, Never → blacklist.
      If the dialog times out, the copy action is automatically blocked.

      In the extension's interface, you can manage your allowed and blocked domains.
      Entries match the domain and its subdomains.
      A blocked entry has priority over an allowed one.
      Use ⇅ TXT to export both lists to one file or import/merge another.

      Site not working?

      Clipboard Buckler is disabled on whitelisted sites.
      If the current site is not working properly or broken, add it to the whitelist and refresh the page.
      If the issues still persist, you can temporarily disable the extension at the browser level and then refresh the current page.
